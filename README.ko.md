## 자주 묻는 질문

### GitHub Risers가 뭔가요?

총 스타 수가 아니라 하루에 늘어난 스타 수로 GitHub 저장소를 줄 세운 랭킹입니다. AI가 메인이고 카테고리가 여섯 개 더 있습니다. 데이터는 GitHub API에서 스크립트로 만듭니다. [더 보기](docs/FAQ.md#what-is-github-risers)

### GitHub Trending과 뭐가 다른가요?

GitHub Trending은 GitHub 공식 페이지입니다. GitHub Risers는 독립적인 오픈 소스 프로젝트로, 규칙을 공개하고 5개 언어를 지원하며 갱신 때마다 기록을 남깁니다. GitHub와는 관련이 없습니다. [더 보기](docs/FAQ.md#is-it-the-same-as-github-trending)

### 얼마나 자주 갱신하나요?

매일 갱신합니다. 실행할 때마다 보관합니다. [더 보기](docs/FAQ.md#how-often-is-it-updated)

### 숫자는 어떻게 계산하나요?

최근 7·30·365개의 완료된 UTC 일에 늘어난 스타를 그 일수로 나눕니다. 숫자는 모두 GitHub API에서 가져오며 손으로 넣거나 추정하지 않습니다. [더 보기](docs/FAQ.md#how-is-the-growth-rate-computed)

### 어떻게 보고 어떻게 기여하나요?

아래 랭킹을 보거나 latest/의 상위 20개를 보세요. 수록 프로젝트를 추가하려면 data/projects.json(다섯 언어)을 고친 뒤 pull request를 보내세요. [더 보기](docs/FAQ.md#how-can-i-suggest-a-project-or-report-a-mistake)
